0. QUICK START
================================================================================

Frontend .env (Expo):
  EXPO_PUBLIC_API_URL=http://localhost:8080         # dev
  EXPO_PUBLIC_API_URL=https://xxx.railway.app       # prod
  EXPO_PUBLIC_PRIVY_APP_ID=                         # optional, see §26
  EXPO_PUBLIC_PRIVY_CLIENT_ID=                      # optional, see §26

Install:
  npm install @tanstack/react-query axios zustand react-native-sse
                @microsoft/fetch-event-source

Minimal boot:
  1. GET  /api/tokens?chain=ethereum               → render markets
  2. WS   /ws/prices?chain=ethereum                → live prices (REST polls if quiet)
  3. GET  /api/auth/nonce + POST /api/auth/verify  → get JWT (lazy, only on Trade click)
  4. POST /api/quote (JWT)                         → quote (gasless or self-exec)
  5a. Gasless (default): sign toSign → POST /api/order → WS /ws/order/:quoteId
  5b. Self-execution: broadcast quote.tx from wallet (user pays gas)
  6. GET  /api/prices?chain= every 15s             → REST fallback when WS quiet

5. AUTH (Wallet Sign → JWT)
================================================================================

Flow:
  1. GET  /api/auth/nonce?wallet=0x...  → { "nonce": "Sign this message..." }
  2. wallet.personalSign(nonce)         → 65-byte hex signature
  3. POST /api/auth/verify { wallet, signature } → { "token": "<jwt 24h>" }

Errors: 400 wallet required / invalid request / missing fields,
        401 nonce expired or not found / invalid signature format / signature does not match wallet.

Implementation: src/auth/walletAuth.ts (`authenticateWallet(address, signMessage)`).
Triggered by the wallet abstraction (§26) — never by the user directly.

6. TOKENS
================================================================================

GET /api/tokens?chain=ethereum  (none, 24h cache)

Response Token[]  (canBuy || canSell). Preserve EXACT checksum casing

6b. PRICES (REST FALLBACK)
================================================================================

GET /api/prices?chain=ethereum  (no auth)

Backend sources (priority):
  1. Bebop Price WS stream (when entitled) → real-time order books
  2. Bebop /pmm/{chain}/v3/token-info REST seed (~30s)
     → priceUsd for ALL ~283 tradeable tokens, no Price API entitlement needed

Status today: option 2 active. /api/prices and /ws/prices serve full token
coverage on ethereum. Bebop Price WS still 403 until entitlement enabled.

Response:
  {
    "chain": "ethereum",
    "updatedAt": 1780812883,
    "prices": { "0xc02a...756cc2": 1600.48, ...283 entries },
    "books":  { ... }                        // empty until Price WS entitled
  }

Frontend rule (`useRestPrices`):
  Always poll when (Date.now() - priceStore.lastUpdated > 15s) OR (!wsConnected).
  Backs off automatically once WS pushes resume.

================================================================================
7. QUOTE (RFQ — Gasless or Self-Execution)
================================================================================

POST /api/quote  (JWT, 100/min)

Request body:
  { chain, sellToken, buyToken, sellAmount, takerAddress, gasless? }

  takerAddress MUST equal JWT.wallet (case-insensitive).
  Omit `gasless` to use the server default (BEBOP_GASLESS, true).

Two execution modes:

  GASLESS (gasless: true)
    Bebop status:   QUOTE_SUCCESS
    Response field: toSign (EIP-712 message)
    Next:           sign toSign → POST /api/order { quoteId, signature }

  SELF-EXECUTION (gasless: false)
    Bebop status:   SIG_SUCCESS
    Response field: tx { to, data, from, value, gas, gasPrice }
    Next:           wallet.sendTransaction(tx)  — POST /api/order NOT called

Response (selected fields):
  quoteId, status, gasless, expiresAt, chainId,
  buyTokens / sellTokens  : Record<addr, {amount, decimals, symbol, priceUsd,
                                          amountBeforeFee?, minimumAmount?}>,
  toSign? / tx?,
  settlementAddress, onchainOrderType,
  priceImpact, feeBps, feeTier   // explorer 10bps · trader 15bps · pro 8bps

Errors: 400 invalid request / missing required fields / sellAmount must be > 0 /
        quote expired before delivery / 401 missing or invalid token /
        403 takerAddress must match authenticated wallet / 429 rate limit /
        502 <Bebop verbatim>.

Implementation: `useQuote()` mutation. On success → `tradeStore.setQuote(q)`.

================================================================================
8. ORDER (Submit Signed Trade — Gasless Only)
================================================================================

POST /api/order  (JWT, 20/min)
Used only when quote.gasless === true.

Request: { quoteId, signature }   // EIP-712 signature of quote.toSign
Response: { orderId, status: "Pending", txHash: "" }

After 200: open /ws/order/:quoteId (REST polling as fallback).

Errors: 400 invalid / missing / quote not found or expired,
        403 quote wallet mismatch, 429, 502 order submission failed.

================================================================================
9. ORDER STATUS
================================================================================

GET /api/order/:quoteId/status  (JWT)
Response: { orderId, status, txHash, amounts? }
Status lifecycle: Pending → Settled | Confirmed | Failed.

Implementation (`OrderStatus` component):
  WS push drives `orderStore.setStatus(...)`. If we go > 5s without a WS
  update on a non-terminal order, `useOrderStatus(quoteId, true)` kicks in
  and polls every 2s until terminal.

13. LIVE PRICES (WebSocket + REST Fallback)
================================================================================

WS  ws[s]://<API>/ws/prices?chain=ethereum   (no auth)

Server pushes a snapshot immediately, then deltas. parsePriceUpdate.ts
handles every shape the backend or Bebop emits:
  A. Normalized snapshot   { chain, updatedAt, prices, books? }
  B. Legacy wrapper        { prices: {addr: usd} }
  C. Flat address map      { addr: usd, ... }
  D. Raw Bebop books       { "base/quote": { bids, asks, last_update_ts } }

Implementation:
  `src/ws/priceSocket.ts` is a reference-counted singleton. Multiple screens
  call `subscribePriceFeed(chain)`; only the first opens the socket, only
  the last close-out tears it down. Exponential reconnect 1s → 30s.
  Sets `priceStore.wsConnected`.

Pair with `useRestPrices` (poll /api/prices when stale or WS down).

14. ORDER UPDATES (WebSocket)

16. AXIOS CLIENT (src/api/backend.ts)
================================================================================

`api = axios.create({ baseURL: getApiBaseUrl(), timeout: 15s })`

Interceptors:
  request   – attach `Authorization: Bearer ${jwt}` from walletStore
  response  – on 401 → walletStore.clearJwt(); normalize errors to Error(message)

URL helpers:
  getApiBaseUrl()  – dev-aware: rewrites localhost to LAN IP on native devices
                     via expo-constants (web returns the raw env value)
  getWsBaseUrl()   – same, with http→ws / https→wss swap

`apiPaths` exports stable paths for every endpoint.

20. FULL TRADE FLOW (UX-aligned, this app)
================================================================================

Markets (tab)               — no wallet required.
                              · GET /api/tokens, WS /ws/prices, useRestPrices poll.
                              · "Connect" pill in header → ConnectWalletModal.

Token Detail /token/:symbol — no wallet required.
                              · useTokenPrice(token.address) drives chart card.
                              · Public /api/news + (if JWT) SSE /sse/news.
                              · "Trade {symbol}" CTA:
                                  – wallet present  → preselect tokens, push /trade
                                  – wallet missing  → open ConnectWalletModal,
                                                       then preselect + push /trade.

Trade (tab)                 — wallet required.
                              · If no wallet, shows a clean "Connect to trade" card.
                              · TradePanel: network + execution mode (gasless | self)
                                + sell token + amount + buy token. Any change clears
                                the active quote.
                              · POST /api/quote → setQuote.
                              · QuoteTimer counts down; on expiry, auto-refresh
                                request.

Confirm                     — branches on quote.gasless:
                              · Gasless     wallet.signTypedData(buildTypedData(q))
                                            POST /api/order → push /order-status
                                            connectOrderSocket(q.quoteId)
                              · Self-exec   wallet.sendTransaction(q.tx)
                                            setActiveOrder + push /order-status
                                            (REST polling carries it from here)

Order Status                — WS-first, REST polling fallback after 5s silence.
                              Terminal: invalidate ['portfolio'], show CTA
                              ("Trade Again" or "Get New Quote" on failure).

Portfolio (tab)             — wallet required.
                              · GET /api/portfolio (per chain).
                              · markPrices seed priceStore for live P&L.

Settings (tab)              — wallet card (connect / sign in / disconnect),
                              chain picker, haptics toggle.

22. SECURITY RULES (frontend MUST follow)
================================================================================

NEVER in frontend (no EXPO_PUBLIC_* leaks):
  ✗ BEBOP_API_KEY  ✗ BEBOP_PARTNER_ID  ✗ BEBOP_FEE_RECIPIENT
  ✗ JWT_SECRET     ✗ CRYPTOPANIC_API_KEY  ✗ BENZINGA_API_KEY

ONLY in frontend:
  ✓ EXPO_PUBLIC_API_URL
  ✓ EXPO_PUBLIC_PRIVY_APP_ID / EXPO_PUBLIC_PRIVY_CLIENT_ID  (public by design)

NEVER send to backend:
  ✗ fee, fee_recipient, source, source-auth, origin_address (server injects).

ALWAYS:
  ✓ takerAddress = JWT wallet address.
  ✓ Use getWsBaseUrl()/getApiBaseUrl(); never hardcode localhost.
  ✓ Sign / broadcast before expiresAt.
  ✓ Preserve token address casing from GET /api/tokens.
  ✓ JWT lives in walletStore (in-memory). On native, replace with SecureStore.

26. WALLET ABSTRACTION & UX GATING (this app)
================================================================================

Single source of truth: `src/wallet/WalletProvider.tsx`. Mounted under
`QueryClientProvider` in `app/_layout.tsx`.

Consumer hook:
  const wallet = useWallet();
  wallet.status                              'idle' | 'connecting' | 'connected' | 'error'
  wallet.address                             string | null
  wallet.source                              'metamask' | 'rabby' | 'privy-...' | 'manual'
  wallet.isAuthenticating                    boolean
  wallet.availableAdapters                   ('web-injected' | 'privy' | 'manual')[]
  wallet.connect({ adapter?, manualAddress? })
  wallet.authenticate()                      runs §5 against the active adapter
  wallet.connectAndAuthenticate(opts)        idempotent compose
  wallet.disconnect()                        clears address+jwt+trade+order stores
  wallet.signTypedData(typedData)            EIP-712 for gasless confirm
  wallet.sendTransaction(quote.tx)           self-execution path

Adapter selection (first match wins):
  1. Privy            available iff EXPO_PUBLIC_PRIVY_APP_ID set AND @privy-io/expo
                      installed (today: disabled stub; supply APP_ID + add SDK
                      → drop a bridge into `setPrivyBridge`).
  2. Web injected     available iff IS_WEB && window.ethereum.
  3. Manual           always available; dev-only — cannot sign.

Cross-platform behavior:
  Web  : MetaMask / Rabby / Coinbase via window.ethereum.
         accountsChanged → clear JWT + active quote.
         chainChanged    → clear active quote.
  iOS / Android: Privy when configured; otherwise the modal still works for
         browsing (you can paste an address with "Manual address" — read-only).

UX gating:
  · Markets and /token/:symbol are browseable without a wallet.
    A persistent "Connect" pill lives in the Markets header.
  · The Trade tab gates with a "Connect to trade" CTA when wallet absent.
  · The "Trade {symbol}" button on Token Detail opens the connect modal,
    then routes into Trade with that pair preselected (USDC ↔ token).
  · Portfolio gates with "Connect to view your trades".

Sign-in flow (§5):
  ConnectWalletModal calls `wallet.connect({...})`, then immediately runs
  `wallet.authenticate()` for any adapter that can sign. Result is a JWT in
  walletStore, attached automatically by the axios interceptor.
